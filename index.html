制作流程拆解

Production Pipeline · 4 Stages
  1. 01Blender 整理 & UDIM 准备

    统一材质并建立 4096×4096 拼贴图像；按零件分组建立 UDIM 分块（1001 / 1002 …）， 通过 UV 编辑器批量位移 UV 到对应分块；履带板等重复件 UV 完全重叠共用材质， 大幅降低贴图冗余。最终整合为单一 FBX 导出。

  2. 02Substance 3D Painter 绘制

    导入 FBX 时启用「UV 平铺工作流」，全选 Texture Set 统一烘焙使接缝自动融合； 跨分块连续绘制，按规范命名导出（如 tank_BaseColor.<UDIM>.png）， 并对 4K 贴图做降分辨率与 ORM 打包瘦身。

  3. 03Blender 贴图回接

    使用 Substance Textures Importer 插件批量导入导出文件夹， 勾选 Replace Shader 与 OpenGL Normals；将图像节点来源改为「UDIM 分块」， 并严格区分色彩空间：BaseColor 保持 sRGB，其余通道设为非色彩。

  4. 04性能优化与渲染

    3D 视图开启「简化」将预览分辨率限制在 1024 / 2048 以保障操作流畅， 渲染时自动调用 4K 贴图输出高质量成图，兼顾迭代效率与成图精度。
